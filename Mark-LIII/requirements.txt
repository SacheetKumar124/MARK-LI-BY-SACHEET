# ── Optional: text-to-speech engines ──────────────────────────────────────────
# The assistant's voice comes from the Gemini Live session's own audio, so
# these are NOT needed for Jarvis to speak. They exist for core/tts.py, which
# is used only if something is switched to local TTS later. All three of its
# engines are opt-in and installed on demand:
#   pip install edge-tts          # free, needs internet (default engine)
#   pip install kokoro soundfile  # fully offline, ~330 MB model
#   pip install elevenlabs        # cloud, API key required
# If the package is missing, speaking through core/tts.py now raises a message
# naming the package instead of a bare ModuleNotFoundError.

# ── Optional: local wake word ("Hey Jarvis") ──────────────────────────────────
# Deliberately NOT installed by default — it's opt-in. Enable it (and download
# the tiny model) with one click from ⚙ → WAKE WORD in the app, or install it
# yourself with:  pip install openwakeword
#
# Linux OS actions (volume, brightness, screenshots, clipboard, reminders) go
# through core/kali_compat.py, which walks a session-aware backend cascade:
#   volume      wpctl (PipeWire, what Kali ships) -> pactl -> pamixer
#   brightness  logind SetBrightness over polkit (no root, no extra package)
#   screenshot  xdg-desktop-portal -> GNOME Shell dbus -> grim -> scrot/import
#   clipboard   wl-copy/wl-paste -> xclip -> pyperclip
# so no extra Python packages are needed on Linux. macOS uses osascript, Windows
# uses the pycaw / comtypes extras above — nothing Windows-specific is ever
# pulled in on a Linux box.
#
# NOTE for Kali/Debian/Ubuntu: system Python carries an EXTERNALLY-MANAGED marker
# (PEP 668), so `pip install -r requirements.txt` needs either a virtualenv or
# `--user --break-system-packages`. setup.py and core/installer.py add that
# automatically when they detect the marker.
